# 🛒 Simple Shopping Website

A beginner-friendly shopping website built using **HTML, CSS, and JavaScript**.  
This project is perfect for learning basic web development and showcasing on your GitHub profile.

---

## 🚀 Features

- 🛍 Product listing (T-Shirt, Shoes, Watch)
- ➕ Add to Cart functionality
- 🧮 Cart item counter
- 🎨 Clean and simple UI design
- 📱 Beginner-friendly structure

---

## 🧑‍💻 Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
